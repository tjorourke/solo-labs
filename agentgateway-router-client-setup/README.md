# Using vLLM Semantic Router with Cursor and Claude

Sample configuration for the how-to at
<https://mastertheagent.com/solo/agentgateway-router-client-setup/>.

Part 3 of the client setup series. Parts 1 and 2 connect Cursor and Claude to agentgateway.
This part adds compatibility configuration for **vLLM Semantic Router**, a separate service
agentgateway calls through external processing to classify requests for model routing.

The problem: Cursor uses OpenAI Chat Completions and Claude uses Anthropic Messages. The
tested router setup processes OpenAI-format requests; rewriting a Claude request without
changing what the next backend expects can break tool calls. It also expects the virtual
model name `auto`, rather than the name in a client's model picker.

The intake listener normalises that name and converts Messages into Chat Completions before
classification. Replies are converted back for Claude. These files assume the router and
model-serving gateways already exist; the task-routing lab linked below builds them.

[Part 4: Agentdesktop fleet mode](https://mastertheagent.com/solo/agentdesktop-fleet-kind/)
then demonstrates centrally managed client settings and short-lived gateway credentials
with Claude Code. A semantic router is optional for that deployment.

`yaml/` is the Enterprise CRDs, `yaml-oss/` the same objects on the OSS CRDs, generated by the
group and kind swap the page describes.

```bash
kubectl apply -f yaml/       # or yaml-oss/
```

| File | What it is |
| --- | --- |
| `00-intake-listener.yaml` | The front door: a second listener on the Gateway you have, because a transformation runs after an external processor on the same listener |
| `10-intake-policy.yaml` | Model name to `auto`, tool filtering per client shape, the question lifted out of the envelope |
| `20-intake-route.yaml` | `/v1/messages` converted to chat completions, everything else passed through with the Host rewritten |

Edit before applying: the Service name `model-gateway.agentgateway-system.svc.cluster.local`
in `20-intake-route.yaml`, which is the gateway this hop forwards to.

These are the files as they run in
[the task routing lab](https://github.com/tjorourke/solo-labs/tree/main/agentgateway-inference-task-routing-eks),
where the hop sits in front of vLLM Semantic Router on a live cluster.
