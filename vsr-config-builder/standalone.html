vLLM Semantic Router and Jev configuration wizard

Answer a few questions about the kinds of request you want to tell apart, and this writes the classifier's configuration: the vLLM Semantic Router values file, or the profile and manifests for a Jev ExtProc adapter. Then it checks the result for the mistake that is hardest to catch by eye: a rule that reads perfectly well and can never fire, because a broader one above it always matches first. Everything runs in this browser, and nothing is sent anywhere.
