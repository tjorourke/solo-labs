TrustUsBank · software delivery

Demo 3 : A PM agent and an engineer agent ship a change

The bank's online-banking app runs twice in this cluster, in trustusbank-staging and trustusbank-prod. A PM agent turns a product request into a GitHub issue. An engineer agent picks it up and commits the change. The platform builds the commit in Berlin and deploys it to staging. A person approves or denies it, and only an approved image reaches production. Both agents run on Gemma, and they reach tjorourke/trustusbank-payments only through agentgateway.

Platform admin · AgentRegistry governance

Demo 4 : Approve the MCP tools agents may use

Every MCP server in AgentRegistry, with the tools it offers right now, read live through agentgateway. Review each tool's description and input schema, then approve or deny it. The decision is kept on the server's AgentRegistry record. Only approved tools show up in the agent builder below, and each agent's runtime loads only the tools it was granted. Denying a tool also takes it away from any builder agent that already has it.
