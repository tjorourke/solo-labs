DATA CLASSIFICATION · KERNWERK AG

Some of this data cannot leave the region, and developers cannot be trusted to know which

The company

Kernwerk AG, a German industrial manufacturer.

  • 31,000 employees across the EU
  • A US subsidiary
  • A strong works council
  • A strong data protection function

“We have three classes of data. One class can go anywhere. One class must stay in the EU. One class must never touch a model we do not host ourselves.”

“Today that distinction lives in a policy document and in the heads of about four people. Developers are shipping agent features weekly and I have no way to enforce any of it.”

Head of Data Protection, Kernwerk AG
Class 1 · Can go anywhereExternal models, such as Claude
Class 2 · Must stay in the EUModels hosted in EU regions only
Class 3 · Never leaves KernwerkKernwerk's own models, in Kernwerk's private datacenter

The gateway reads every prompt and sends it to the only place it is allowed to go, for every developer and every agent.
