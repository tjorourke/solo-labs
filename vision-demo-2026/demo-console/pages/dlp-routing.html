Data classification · Kernwerk AG

Route prompts according to Kernwerk's data policy.

Kernwerk restricts which models can process company data. This demo uses the gateway to classify prompts and route them to an external provider, an EU-hosted model or a model running on Kernwerk's own infrastructure.

“Public data can go to external providers. Some internal data has to stay in the EU, and restricted data can only go to models we host ourselves.”

“We have this written down, but developers are adding agent features every week. We need to apply the policy to those requests and check where the data went.”
