Enrol this Mac

Three steps, then Claude Code and Claude Desktop both talk to the EKS model gateway and the key never sits on the laptop. Step 1 asks for your password once, because Claude Desktop reads its policy from the machine's managed preferences and only a daemon running as the machine can write them. After that everything is policy.

  1. 1. Install the daemon

    Registers Agentdesktop as a system service and adds you to the group allowed to talk to it. One macOS password prompt.

  2. 2. Sign in

    Opens the company identity provider. Sign in as bob / password. The device enrols against that identity, and the gateway token is minted from it.

  3. 3. Publish a policy

    Pick Claude Code and Claude Desktop below. Restart Claude Code and reopen Desktop to see it land.

    Go to policies
Claude Code only, without a password

A daemon running as you can manage Claude Code on its own. It cannot manage Claude Desktop, and it refuses a policy that carries Claude Desktop whole, so both clients end up unmanaged. Use this only with the Claude Code-only policy.
