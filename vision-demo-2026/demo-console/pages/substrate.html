DEMO 07 · Substrate

Agent Substrate

Agents do not need a pod each. They live as actors, they are snapshotted when they go quiet, and they come back on whichever worker is free.

An idle agent still holds a pod, and a thousand agents is a thousand pods doing nothing. Substrate gives a worker several actors, checkpoints each one to object storage between turns, and restores it on the next message. The calls out still go through the gateway.

ActorAn agent's live state. It exists while it is answering, not all day.
WorkerA sandboxed process that hosts many actors, one at a time each.
SnapshotThe actor written to S3 when it goes quiet, and read back on the next turn.
GatewayEvery model and tool call still leaves through agentgateway.
